# 麦麦预算助手 · McD Budget Buddy

基于麦当劳 MCP 的点餐辅助 Skill，根据门店、预算和饮食偏好，推荐最多两套经过实时价格接口核算的到店自取方案。

## 项目状态

开发中。已通过 WorkBuddy 完成门店、菜单、优惠券查询及套餐选配价格核算的探索验证；可安装的 Skill 尚未完成。本仓库目前提供项目规划，不提供可运行版本。

## 第一版范围

1. 查询附近门店，由用户选择门店。
2. 获取当前菜单、可用优惠券和套餐详情。
3. 按预算与偏好组合餐品，将具体选配提交价格核算。
4. 展示最多两套方案，以及价格依据和未确认事项。

第一版仅查询和计算，不执行下单、领券或积分兑换。历史验证价格不代表实时价格；价格响应不回显选配时保留相应说明。
