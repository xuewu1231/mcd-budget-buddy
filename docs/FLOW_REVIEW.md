# 0.9.1 链路与恢复检查

本轮围绕选店、已有券、换选配、确认和支付进度收尾；未增加真实领券、取消、代付或其他账户操作。

| 用户遇到的情况 | 改后行为 |
|---|---|
| 确认前金额变化或核价过期 | 明确本次未创建，保留搭配，可重新核价并核对 |
| 失效券、配送条件变化、选配失效或超预算 | 回到方案重新选择；不沿用原低价、不静默移除已选券 |
| 创建请求超时、断线或响应未知 | 先查最近订单或官方 App，不能直接重试创建 |
| 查券期间切换门店或配送地址 | 按门店、场景、地址与请求版本隔离，旧成功或失败均不覆盖新场景 |
| 确认准备返回缺失、字符串或负数金额 | 拒绝进入确认及支付链路，避免NaN或未知金额 |
| 已启用用券但更新时查券失败 | 保留无券实价并明确说明查询失败，不当成没有券 |
| 查看麦乐送门店位置 | 说明按地址确认配送资格，不展示假的距离或送达时长 |
