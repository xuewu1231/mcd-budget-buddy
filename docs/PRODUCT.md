# 第一版产品范围

麦麦预算助手是手机优先网页 + 独立 WorkBuddy Skill。网页负责操作和方案比较，Node 后端负责真实 MCP 查询、套餐候选筛选、完整选配核价；共享规则文件约束两种入口。

## 用户流程

输入地点、预算和餐品偏好（或提取有限关键词）→ 查询附近门店 → 点击选择 → 查询菜单和优惠券 → 读取候选套餐详情 → 选定具体饮料 → 官方核价 → 比较最多两套方案。

点选餐品托盘，在图形弹窗选择当前接口返回的子项并核价；固定部分明确说明不能替换。也保留展开全部选配的下拉入口。调整饮料后立即显示待核算，旧金额失效，重新核价后再显示金额。两方案与同款跨店金额以总价横向图表示，不拆分未知单项价格。“选这套”只表达用户选择，不创建订单。预算不足时展示有限候选的检查范围及预算调整入口。第一版一人份、当前到店自取，不创建订单。

## 两种入口

网页：本地 Node 服务 + 浏览器，电脑与手机布局自适应。查询使用用户本地配置，仅提供真实数据；未连接或查询失败显示原因，不以示例补位。

WorkBuddy：直接导入打包后的 Skill，或在工作目录读取 SKILL.md。读取 shared/policy.json，并用 scripts/check_plan.py 校验规范化计划；允许客户端 AI 更灵活地理解需求。网页的规则解析不能被描述成 LLM。

## 可扩展方向

完成真实端到端测试后，再考虑优惠券适用规则、单品组合搜索、多用户独立认证及公网部署。先用同一个套餐详情模型完成本版本，避免前端和 Skill 各自猜测数据字段。
